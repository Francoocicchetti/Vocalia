# Vocalia 0.0.4 — Preview

**Pre-release · Still in development. This is not the finished 1.0 release.**

The public version number is now **0.0.4**, replacing the previous **1.0.4** label. This is a versioning change: automatic transcription on import, manual speaker analysis, six interface languages and existing features are preserved. Updating uses the same local history and model folders.

## Download

- **Windows 11 · Intel / AMD:** [Vocalia-0.0.4-Windows-x64-Setup.exe](https://github.com/Francoocicchetti/Vocalia/releases/download/v0.0.4/Vocalia-0.0.4-Windows-x64-Setup.exe)
- **Mac · Apple Silicon · macOS 26+:** [Vocalia-0.0.4-macOS-AppleSilicon.zip](https://github.com/Francoocicchetti/Vocalia/releases/download/v0.0.4/Vocalia-0.0.4-macOS-AppleSilicon.zip)

Windows portable ZIP and complete source are also under Assets. Use Setup.exe for normal Windows installation. Choose the audio language, then add or drop recordings to transcribe automatically. A missing model is downloaded first. Speaker analysis is manual.

Mac is not Apple-notarized: move the app to Applications; if blocked, use System Settings → Privacy & Security → Open Anyway. Windows is unsigned. [Mac installation guide](https://github.com/Francoocicchetti/Vocalia/blob/main/INSTALL-MAC.md).

Historical releases remain available for reference and are marked as pre-releases. They are not a declaration of production readiness. Windows package tests run on Windows Server x64; physical Windows 11 validation is still needed. Check quotations, names and figures against the recording.

# Español

**Versión preliminar · En desarrollo. Todavía no es la versión 1.0 definitiva.**

La numeración pasa a **0.0.4** y sustituye a la etiqueta anterior **1.0.4**. Se conservan la transcripción automática al agregar archivos, el análisis manual de voces, los seis idiomas de interfaz y las demás funciones. La actualización utiliza las mismas carpetas de historial y modelos.

## Descarga

- **Windows 11 · Intel / AMD:** [Vocalia-0.0.4-Windows-x64-Setup.exe](https://github.com/Francoocicchetti/Vocalia/releases/download/v0.0.4/Vocalia-0.0.4-Windows-x64-Setup.exe)
- **Mac · Apple Silicon · macOS 26+:** [Vocalia-0.0.4-macOS-AppleSilicon.zip](https://github.com/Francoocicchetti/Vocalia/releases/download/v0.0.4/Vocalia-0.0.4-macOS-AppleSilicon.zip)

Elige el idioma del audio y agrega o arrastra las grabaciones: se transcriben automáticamente. Si falta un modelo, se descarga primero. La separación de voces sigue siendo manual.

En Mac, mueve la app a Aplicaciones y, si macOS la bloquea, usa Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente. [Guía de instalación](https://github.com/Francoocicchetti/Vocalia/blob/main/INSTALL-MAC.es.md).

Las publicaciones anteriores quedan como referencia histórica y también se identifican como preliminares. Revisa las cuñas, nombres y cifras escuchando el original.
