WINDOWS 11 (Intel / AMD x64)
Download and run Vocalia-1.0.1-Windows-x64-GuideFix-Setup.exe. Follow the installer and open Vocalia from the Start menu. No manual extraction or Python required.
Descarga y ejecuta Vocalia-1.0.1-Windows-x64-GuideFix-Setup.exe. Sigue el asistente y abre Vocalia desde Inicio. No necesita descomprimir ni instalar Python.

MAC / MACBOOK (Apple Silicon M1+, macOS 26+)
Download Vocalia-1.0.1-macOS-AppleSilicon-GuideFix.zip. Extract, drag Vocalia.app to Applications and open it.
Descarga Vocalia-1.0.1-macOS-AppleSilicon-GuideFix.zip. Descomprime, arrastra Vocalia.app a Aplicaciones y ábrela.

En ambas apps, elige el idioma de interfaz y audio, prepara el modelo y agrega grabaciones. La descarga inicial de modelos necesita internet; después el reconocimiento es local.
